MemeForger API

Documentation officielle des points d'ancrage (Endpoints) de l'API de génération de memes.

POST /api/new

Génère un tout nouveau meme à partir d'un contexte et d'une demande utilisateur en utilisant l'IA.

Body Parameters (JSON)

Paramètre Type Requis Description
context string Requis Contexte général du meme (min. 20 caractères).
user_prompt string Requis La demande précise de l'utilisateur pour le meme.
temperature number Optionnel Créativité de l'IA (entre 0.0 et 2.0). Par défaut: 0.7.

Réponse Succès (200 OK)

{
  "result": {
    "image": "base64_string_or_image_url_here"
  }
}
POST /update

Modifie ou édite une image de meme existante (base_image) en fonction d'une nouvelle demande utilisateur.

Body Parameters (JSON)

Paramètre Type Requis Description
base_image base64 string Requis L'image de base encodée en Base64 à modifier.
context string Optionnel Nouveau contexte ou indication (min. 10 caractères).
user_prompt string Requis Instructions spécifiques de modification.
temperature number Optionnel Créativité de l'IA (entre 0.0 et 2.0). Par défaut: 0.7.

Réponse Succès (200 OK)

{
  "result": {
    "image": "base64_string_or_image_url_here"
  }
}
